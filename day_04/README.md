# Day 04 — Phylogenetics, IQ-TREE, and Nextclade

## Overview

Day 04 focuses on phylogenetic analysis and clade assignment for pathogen genome data. 
You will learn how reconstructed genomes can be compared, how phylogenetic trees are inferred, and how these results can support genomic surveillance.

The practical session introduces **IQ-TREE** for phylogenetic tree inference and **Nextclade** for rapid genome quality control, clade assignment, and mutation profiling.

## 🎯 Learning goals

By the end of Day 04, you should be able to:

- explain why phylogenetics is useful in pathogen genomic surveillance
- understand the basic principles of sequence alignment and tree inference
- distinguish between samples, sequences, alignments, and phylogenetic trees
- understand common phylogenetic tree terminology, including tips, nodes, branches, and support values
- run or interpret basic phylogenetic analyses with `IQ-TREE`
- understand the purpose of model selection and bootstrap support
- use `Nextclade` to assess genome quality and assign clades
- interpret basic Nextclade outputs, including mutations, missing data, and QC warnings
- compare the roles of IQ-TREE and Nextclade in a genomic analysis workflow
