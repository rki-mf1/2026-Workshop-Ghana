# Mapping with `bwa mem` 

## 🎯 Learning goals

By the end of this practical, you should be able to:

- use bwa to index a reference genome
- use bwa mem to map fastq sequence data to a reference genome


## Overview


## 1. Activate the Conda environment

Activate the Conda environment that contains `bwamem2`.

```bash
conda activate bwamem2 
```

Check that `bwa` is available.

```bash
bwa-mem2
```

If the command prints a version number, the environment is ready.

## 2. Prepare the working directory

Move to the main workshop repository.

```bash
cd ~/2026-Workshop-Ghana
```

Create a working directory for this practical.

```bash
mkdir -p analysis/map
cd analysis/map
```

Create directories for input reads and output files.

```bash
mkdir -p input
mkdir -p output
mkdir -p index
```


## 3. Index the reference genome utilizing `bwa index`

As a first step, in order to use _bwa_ we need to build an index of the reference sequence, that we want to map against. Before we can build the index we need to unpack it from the training files.

```bash
cp ~/2026-Workshop-Ghana/data/references.tar.gz .
tar -xvzf references.tar.gz
mv references/reference.fasta index
```

We just needed the reference fasta file, we don't need the folder that we just unpacked, so we can delete it.

```bash
rm -r references
```

Now we can build the index. The index is a data structure that helps the mapping algorithm too quickly find matching sequences.

```bash
bwa-mem2 index index/reference.fasta
```

Have a look at what files were generated by this command.

```bash
ls -lh index
```

## 4. Map with `bwa mem`

Now finally we can map the reads of peter against the monkey pox reference sequence. We will use _bwa mem_ for that. The basic structure of a `bwa mem` command is:

```bash
bwa-mem2 mem index/reference.fasta input/peter_1P input/peter_2P > output/peter.sam
```

Note that we only gave the prefix of the index files, _bwa mem_ knows which files of the index it actually needs and assumes that they are next to the reference fasta file. 

Next we have to sort mapping file `peter.sam`. We will use _samtools sort_ for that. 

```bash
samtools sort output/peter.sam > output/peter.sorted.bam
```

We do want to have a look at what we did. We can the software _IGV_ for that. IGV has a graphical user interface, it is very handy for looking at genomic data. For IGV we need a data structure so that it can quickly access different parts of the mapping file `peter.sorted.bam` that we just created. So again we will build an index. 

```bash
samtools index output/peter.sorted.bam
```

### 💬 Discussion

- What is the main difference between peter.sam and peter.sorted.bam? (use `head` and `ls -lh`) 

## 5. Look at the results with IGV

Now you can load up IGV. There should be a folder containing IGV in your home directory. You can load it like this.

```bash
~/IGV_Linux_2.17.2/igv.sh
```




## 📌 Summary

In this practical, you used `bwa mem` to perform short read mapping and you used `samtools` to sort and index the result. Furthermore you looked at the results with IGV.
